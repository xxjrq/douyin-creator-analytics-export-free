# Free Douyin Creator Analytics Export

Export visible first-party creator metrics such as plays, completion, clicks, likes, comments, favorites, and follower changes as CSV, JSON, or Markdown. No third-party API key is required.

Requires [Easy WebBridge](https://github.com/xxjrq/easy-webbridge), with a [Gitee mirror](https://gitee.com/xxjrq/easy-webbridge) available.
